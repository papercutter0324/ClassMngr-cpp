# C48 Useful Links capture evidence

These four 1024×720 PNGs capture the Next shell’s expanded Useful Links group
with the seven link labels visible. The captures were produced by
`ClassMngrNextBootstrapTests` using Qt’s offscreen platform for English and
Korean with Light and Dark themes. No URL opener was invoked and no network
request was made.

`capture-manifest.json` records each image’s locale, theme, byte length, and
SHA-256 digest. The corresponding build outputs are under
`build/macos-clang-debug/useful-links-visual-captures/`.
