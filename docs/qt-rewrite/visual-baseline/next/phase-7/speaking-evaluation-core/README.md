Synthetic captures of the Next Speaking Evaluation page. Each PNG is 1440 × 880.
The locale/theme matrix is English (`en_US`) and Korean (`ko_KR`), in light and
dark themes.

| Locale | Light | Dark |

| Korean (`ko_KR`) | [PNG](ko_KR-light.png) | [PNG](ko_KR-dark.png) |

The set supports review of the page's presentation across the locale/theme
matrix. These images are presentation evidence, not pixel-parity evidence. The
[manifest](manifest.json) records each capture's locale, theme, and filename.
