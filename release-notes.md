# ClassMngr 0.19.0 Release Notes

ClassMngr 0.19.0 brings personal teaching tools together in a new My Workspace,
adds typed signatures, refines class navigation, and improves startup
performance and reliability.

## My Workspace and Signatures

- Combined Personal Details, My Schedule, and Calendar into one **My
  Workspace** page. The Schedule tab opens by default, while Calendar data
  loads only when you open that tab.
- Added typed signatures. Type your name and choose from four handwriting
  styles, or continue using a signature image.
- Improved signature previews in dark mode.

## Classes and Navigation

- Split class information and co-teacher management into separate tabs.
- Analytics and Evaluations are now hidden by default for M1, M2, and M3
  classes. You can show them again from Navigation Bar preferences.
- Added an option to open Analytics and Evaluations to the current term, or to
  the previous term when the current evaluation has no entries.
- Simplified the sidebar by removing the separate Individual Classes node.

## Performance and Reliability

- Reduced startup work and memory use by loading pages, resources, and
  nonessential features only when needed.
- Improved startup reliability when an expected resource folder is missing.
- Added a **Don't Show Again Today** option to birthday notices.
- Improved Korean text rendering to better match the selected interface font.
